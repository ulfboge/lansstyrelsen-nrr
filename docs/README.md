# docs/

Dokumentation för naturrestaureringsuppdraget (NRR) i Södermanlands län.

GitHub Pages använder filerna i den här mappens rot: `nrf-guide.html` och `datamodell.md` länkas från `index.html`. Flytta inte dem utan att uppdatera hemsidan.

## Innehåll

| Sökväg | Vad som hör hemma här |
|--------|------------------------|
| `Projektplan_NRF_Sodermanland_2026_v2.docx` | Formell projektplan 2026–2027 (Word, v2.0) |
| `arkiv/projektplan.md` | Arkiverad projektplan v1.1 (ersatt av Word-planen) |
| `datakallor.md` | Datakällor och licenser |
| `datamodell.md` | Bedömningsschema och fältstruktur |
| `verktyg.md` | Pipeline-dokumentation (privata `natura-2000`-repot) |
| `planner_struktur.md` | Microsoft Planner-upplägg vid tjänststart |
| `Implementering av NRF Sörml.docx` | Enhetens plan för implementering av NRF i Sörmland |
| `nrf-guide.html` | Publik NRR-guide (GitHub Pages) |
| `nrf-karta.html` | Karta till presentationen |
| `nrf-presentation-v3.pptx`, `nrf-talarmanus-och-faktakoll.docx` | Presentation om NRF med talarmanus (v2 i `arkiv/`) |
| `_VÄS 2024.pdf` | VÄS 2024 (uppladdad 2026-10-15) |
| `arkiv/` | Ersatta versioner: projektplan v1.1, presentation v2, platsannonsen och underlaget för saneringen av jobbmappen i september |
| `skyddadnatur/natura2000/` | Bevarandeplaner från [Skyddad natur](https://skyddadnatur.naturvardsverket.se/) (PDF lokalt, index i Git) |
| `tuva/sodermanland/` | TUVA ängs- och betesmark från [Jordbruksverket](https://etjanst.sjv.se/tuvaut/) (CSV + index i Git, rapporter/GIS lokalt) |

NNK-arbetet (underlag, analys, fältprotokoll, uttag) ligger inte här utan i det privata [natura-2000](https://github.com/ulfboge/natura-2000) och arbetsdokumenten i det publika [nnk-granskning-2026](https://github.com/ulfboge/nnk-granskning-2026).
