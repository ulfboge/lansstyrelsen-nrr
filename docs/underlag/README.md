# docs/underlag/

Källmaterial från Naturvårdsverket och den publika Natura naturtypskartan. Ändra inte filerna här — de är nedladdade original. Egna arbetsdokument hör hemma i `docs/nnk/`.

## Filer i roten

| Fil | Källa | Används av |
|-----|-------|------------|
| `FAQ - om uppdraget och hur det genomförs_version 1_1.pdf` | NV, 2026-07-03 | Arbetsplan, runbook |
| `D_NNK_statistik_per_N2000_NP_NR_per_260120.xlsx` | NV-statistik per 2026-01-20 | `scripts/analysis/nnk_kunskapslage.py` |
| `kartering.csv` | Attributexport ur publika NNK_YTA | Fallback i `bygg_blankett.py` |

## Undermappar

| Mapp | Innehåll |
|------|----------|
| `handledning/` | Handledning, lathund, kodlista och KartLitS GIS-mall |
| `naturtypskarta/` | Publik NNK för D-län (shapefiler, .lyrx, produktbeskrivning) |

Nya nedladdningar från samverkansytan för Livsmiljötyper läggs här, med nedladdningsdatum i filnamnet.
