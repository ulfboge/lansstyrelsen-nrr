# docs/nnk/

Arbetsdokument för NNK-granskningen 2026 (ref. 2451-2026). Här ligger det vi skriver och använder i det dagliga arbetet — inte källmaterial från NV.

## Filer

| Fil | Roll |
|-----|------|
| `arbetsplan_nnk_2026.md` | Varför och när: mål, batchar, rollfördelning |
| `runbook_nnk_2026.md` | Hur: 68 uppgifter med konkreta steg |
| `kontrollrum_nnk_2026.html` | Gantt, avbockning och uppgiftsöversikt (öppna i webbläsare) |
| `metodik_forvaltarkunskap.md` | Arbetspaket H — förvaltardialogen |
| `blankett_forvaltarkunskap_nnk.xlsx` | Insamlingsblankett till förvaltarna |
| `nnk_kunskapslage_dashboard.html` | Nollmätning av kunskapsläget (öppna i webbläsare) |

Runbook och kontrollrum genereras ur `scripts/analysis/uppgifter.py` med `bygg_kontrollrum.py`. Redigera uppgifterna i skriptet, inte i de genererade filerna.

## Kommande filer

- `granskningslogg.md` — en rad per objekt (uppgift A4.1)
