# data/templates/

Mallar för bedömning av livsmiljötyper. Fältstrukturen är densamma som i ESRI File GDB och Survey123/Field Maps.

| Fil | Användning |
|-----|------------|
| `assessment_template_sodermanland.csv` | En rad per habitatförekomst. Fylls i efter skrivbords- eller fältbedömning. |

Schema och domänvärden finns i `docs/datamodell.md`. Projektion för tillhörande geodata: SWEREF 99 TM (EPSG:3006).
