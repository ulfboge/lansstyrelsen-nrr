# data/uttag/

NNK-uttag från Ajourhålla, ett per tillfälle. Datum i filnamnet gör före/efter-jämförelser möjliga.

## Namnkonvention

```
nnk_YYYYMMDD.gpkg
```

Exempel: `nnk_20261110.gpkg` (uppgift E1.1).

## Innehållskrav

Uttaget ska minst innehålla: NOID, NATURTYP, NATURTYPKO, NATURTYPSS, KARTERINGS, FORANDRING, URSPRUNG, KOMMENTAR, NNK_KOMMEN, REDIGERARE, REDIGERATA, REDIGERATG, SKAPATDATU, MALNATUR1–3, samt de nya tillstånds- och dateringsfälten när de driftsatts.

GeoPackage-filer ignoreras av Git. Dokumentera uttagsrutinen (lager, fält, filter, format) så den går att upprepa identiskt.
